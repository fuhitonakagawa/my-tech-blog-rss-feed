Rust Blog
The Rust Security Response Team was notified that Cargo incorrectly handledsymlinks inside of crate tarballs downloaded from third-party registries,allowing a malicious crate to override the source code of another crate from thesame registry.This vulnerability is tracked as CVE-2026-5223. Rust Blog
The Rust Security Response Team was notified that Cargo incorrectly normalizedthe URLs of third-party registries using the sparse index protocol.
